# Planejamento do site ESG

## Tema

Desenvolvimento de um site acadêmico sobre a aplicação dos princípios ESG
no ramo alimentício.

## Objetivos do sistema

- Apresentar o conceito de ESG;
- Explicar os pilares Ambiental, Social e Governança;
- Mostrar desafios do setor alimentício;
- Apresentar os integrantes da equipe;
- Disponibilizar um canal de contato;
- Armazenar feedbacks enviados pelos visitantes.

## Tecnologias planejadas

- Python;
- Django;
- HTML;
- CSS;
- JavaScript;
- SQLite;
- Git e GitHub.
